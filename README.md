# 魔方学院 · CubeMaster

面向初学者与魔方爱好者的 **3D 魔方在线扭转教程**。在浏览器里选择三阶 / 四阶 / 五阶，跟着教程公式一步步转动魔方，支持一键打乱、一键还原、撤销重做与分步演示。

**在线体验：** https://cube-master-theta.vercel.app

## 功能特性

### 3D 魔方引擎
- 支持 **三阶 / 四阶 / 五阶**，切换阶数即时重建
- 圆角塑料块 + 独立贴纸建模，柔和光照与地面投影
- 鼠标拖动旋转视角、滚轮缩放，阻尼手感顺滑
- smoothstep 缓动的层转动动画，速度可在 85ms ~ 520ms 之间十档调节

### 扭转控制
- 六个面按钮按直觉排布（`U` 上、`L F R B` 中、`D` 下），实时预览当前指令
- 任意角度：**顺时针 90° / 逆时针 90° / 180°**
- 任意层深：四阶支持「第 2 层 / 双层宽转」，五阶支持「第 2 层 / 第 3 层 / 双层 / 三层」
- 三阶支持 `M / E / S` 中层，全阶支持 `x / y / z` 整体转
- 动画进行中连点会自动排队，快速操作不丢失
- 键盘直接扭动：`R L U D F B M E S x y z`，按住 `Shift` 为逆时针

### 教程系统
- **三阶层先法** 7 步：底层十字 → 底层角块 → 中间层棱块 → 顶层十字 → 顶面全黄 → 顶角归位 → 顶棱归位
- **四阶降阶法**：合并中心 → 合并棱块 → 按三阶还原 → 特殊情况（OLL / PLL Parity）
- **五阶降阶法**：3×3 中心 → 三片棱合并 → 按三阶还原 → 特殊情况
- 每组公式配有彩色记号芯片、目标说明与使用时机
- **分步演示**：自动复原后逐步播放，可上一步 / 下一步 / 暂停 / 重播，正在执行的记号高亮显示
- 内置「记号速查」弹窗，随时查阅符号含义

### 辅助操作
- 一键打乱（大阶数会加入宽转，贴近真实打乱）
- 一键还原，复原后显示「已复原」状态
- 撤销 / 重做，操作记录实时展示
- 自动旋转展示、重置视角

## 实现要点

### 状态模型
每个小块（cubie）保存三个信息：

```ts
interface Cubie {
  p: [number, number, number]  // 当前位置（以块为单位）
  m: number[]                  // 3x3 整数旋转矩阵：局部方向 → 世界方向
  stickers: (Face | null)[]    // 6 个局部面的贴纸颜色
}
```

转动某一层时，对该层所有小块执行 `p' = R · p`、`m' = R · m`。矩阵元素始终为整数，**不会累积浮点误差**，因此撤销 / 重做可以精确还原。

### 动画与状态解耦
逻辑状态在指令下发时立即更新到位，动画只是视觉上的插值追赶。动画结束时用逻辑状态精确回写每个小块的变换，既保证「已复原」等判定即时准确，也避免了多次转动后的漂移。

### 转动方向约定
从某个面的**外侧**看，顺时针 = 绕该面外法线 `-90°`（右手定则）。由此可统一推出：

| 记号 | 含义 |
| --- | --- |
| `R L U D F B` | 右 / 左 / 上 / 下 / 前 / 后，顺时针 90° |
| `R'` | 逆时针 90° |
| `R2` | 转 180° |
| `M E S` | 中层，分别跟随 `L` / `D` / `F`（仅奇数阶） |
| `Rw Uw` | 宽转，同时带动最外两层 |
| `3Rw` | 三层宽转（五阶） |
| `2R` | 单片内层，只转从右数第 2 层 |
| `x y z` | 整体转魔方，分别跟随 `R` / `U` / `F` |

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `R L U D F B` | 对应面顺时针转 90° |
| `M E S` | 中层转动（三阶） |
| `X Y Z` | 整体转魔方 |
| `Shift` + 以上按键 | 逆时针转 90° |
| `空格` | 演示播放 / 暂停 |
